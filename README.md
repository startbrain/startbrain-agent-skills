# startbrain-agent-skills

Agent-facing files for [Brain](https://startbrain.io), cyber and AI security awareness for employees,
played like arcade games: four skills (`skills/startbrain`, `skills/startbrain-cybermois`, `skills/startbrain-ai-spring`, `skills/startbrain-arcade`), an Agent Plugins manifest (`plugin.json`)
and instructions for AI agents (`AGENTS.md`).

Install the skill in your agent:

```
npx skills add startbrain/startbrain-agent-skills
```

Machine-readable entry points on the site: https://startbrain.io/llms.txt · https://startbrain.io/index.md ·
https://startbrain.io/.well-known/agent-skills/index.json · https://startbrain.io/.well-known/ard.json
